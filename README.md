# Planilha de Controle e Organização para Declaração de Imposto de Renda

Repositório criado para documentar a Reprodução de uma ferramenta interativa em Excel do Expert Felipe Aguiar, projetada para centralizar, validar e organizar de forma prática todas as informações essenciais necessárias para a declaração de imposto de renda. Foi acrescentado um gráfico de coluna dinâmico,  na aba informes, que apresenta os bancos escolhidos, assim como os valores informados.

##  Objetivos de Aprendizagem
- **Aplicar** os conceitos aprendidos em um ambiente prático de modelagem e automação no Excel.
- **Documentar** processos técnicos de forma clara, estruturada e voltada para portfólio.

##  Sobre o Projeto
Este projeto consiste na criação de um agregador de dados fiscais construído inteiramente no Excel. A ferramenta foi desenvolvida para oferecer uma interface amigável, porém robusta, combinando navegação facilitada, validações automáticas de dados e links rápidos. 

## Estrutura e Funcionalidades da Ferramenta

A planilha foi estruturada com recursos interativos que facilitam a experiência do usuário:

- **Menu de Navegação:** 
  - Um menu principal contendo 3 botões interativos (**Titular**, **Informes** e **Notas**), que direcionam automaticamente o usuário para a aba correspondente.
  - Botões de navegação rápida **“Anterior”** e **“Próximo”**, permitindo alternar fluidamente entre as abas.

- **Abas e Preenchimento de Dados:**
  - **Aba Titular:** Campos dedicados ao preenchimento e organização das informações cadastrais do titular.
  - **Aba Informes:** Seção voltada para o registro de rendimentos bancários, contemplando o nome de até 3 instituições financeiras e seus respectivos valores atuais. Apresenta um Gráfico com essas informações.
  - **Aba Notas:** Espaço para controle detalhado de notas bancárias ou extratos de holerite, permitindo o registro mês a mês de todas as entradas de receita através dos campos **Data**, **Categoria** e **Valor**.
Algumas informações presentes são somente para exemplo, permitindo ter uma noção sobre os aspectos visuais da ferramenta.

##  Diferenciais Técnicos
- Uso de validações de dados para garantir a consistência das informações inseridas.
- Estruturação de menus baseados em botões para navegação dinâmica.
- Organização modular de dados financeiros e fiscais.
